# 🌟 Personal Portfolio | Uresha Magallagodage

A modern, responsive, and dynamic personal portfolio web application built with **React**, **Vite**, and **Tailwind CSS**. Designed with glassmorphism aesthetics, smooth animations, and interactive components to showcase software projects, technical skills, and background.

## ✨ Features

- **🎨 Modern Glassmorphism & UI**: Beautiful visual styling with smooth gradient drifts, glow effects, and responsive design.
- **⚡ Hero Section**: Personal background overview, direct CTAs (Contact Me, Download CV), social links, and an animated tech stack marquee.
- **🙋 About Section**: Highlighting software engineering principles (Clean Code, Performance, Collaboration, Innovation) and mission statement.
- **💻 Projects Showcase**: Displays key software projects and technical achievements.
- **📬 Contact Hub**: Interactive message form, instant clipboard copy for email (`ureshanirmali@gmail.com`), location metadata, and social media integration.

## 🚀 Getting Started

Follow these steps to run the portfolio locally on your machine.

### Prerequisites

Ensure you have **Node.js** (v18+ recommended) installed.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/UreshaN25/uresha-portfolio.git
   cd portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

### Running Locally

Start the Vite development server with HMR:

```bash
npm run dev
```

Open `http://localhost:5173` in your browser.

## 📜 Available Scripts

- `npm run dev` - Starts the local development server.
- `npm run build` - Builds the application for production to the `dist/` directory.
- `npm run preview` - Previews the production build locally.
